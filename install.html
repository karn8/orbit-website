Install Orbit

Orbit works in a modern browser and can be installed like an app on your computer, iPhone or iPad.

Use Orbit on web

  1. Open app.orbitlmsapp.com in Chrome or Edge.
  2. Open the browser menu and choose Install app, or use the install icon in the address bar.
  3. Open Orbit from your desktop or app launcher whenever you need it.

Install on iPhone or iPad

  1. Open app.orbitlmsapp.com in Safari.
  2. Tap the Share button in the browser toolbar.
  3. Choose Add to Home Screen, then tap Add.
